# a-quick-translation-input-tool-for-ArcheRage
It is specifically designed for communication among players of the ArcheRage Russian server
========================================================================
ArcheAge Standalone Quick Translation Input Tool / 
Помощник чата ArcheAge - Быстрый ввод и перевод
========================================================================

【中文说明】
这是一个专为《上古世纪》俄服玩家打造的 100% 独立、绿色的快捷打字翻译输入工具。

✨ 核心亮点：
1. 双击运行：解压直接双击「上古世纪快捷中译俄输入工具.exe」即可运行。
2. 管理员权限：软件会自动申请管理员权限（UAC），这是因为游戏运行于管理员权限下，翻译工具也必须以管理员权限运行才能向游戏聊天框发送按键。
3. 俄罗斯地区免梯直连：默认采用「有道免 Key 极速通道」，在俄罗斯地区无需梯子即可直接秒级翻译，开箱即用。
4. 战术词库：支持本地「glossary.json」游戏术语库，遇到常用暗号秒回地道黑话。
5. 全局热键：在任意界面按下「Ctrl + D」呼出精致的暗黑风输入框，输入中文回车，自动获取翻译、切回游戏聊天框。之后手动按「Ctrl + V」并回车发送，100% 安全，绝不触发反作弊。

📂 目录文件说明：
- 上古世纪快捷中译俄输入工具.exe —— 翻译器主程序
- config.json —— 配置文件（如需配置 DeepSeek/OpenAI Key，双击托盘设置即可）
- glossary.json —— 本地中俄游戏黑话、游戏术语库（可双击托盘设置进行编辑）
- translation_cache.db —— 本地翻译缓存数据库（自动生成，命中历史翻译秒回）

【Описание на русском】
Это независимый, портативный и быстрый помощник для ввода и перевода чата, созданный специально для игроков на русскоязычных серверах ArcheAge.

✨ Ключевые особенности:
1. Запуск в один клик: Просто распакуйте архив и запустите файл «上古世纪快捷中译俄输入工具.exe».
2. Права администратора: Программа автоматически запрашивает права администратора. Это необходимо, так как ArcheAge работает с повышенными привилегиями, и для симуляции нажатий клавиш в игре переводчику также требуются права администратора.
3. Работает в России без VPN: По умолчанию используется бесплатный и быстрый канал Youdao, который стабильно работает на территории РФ напрямую, без использования прокси или VPN.
4. Игровой глоссарий: Поддерживает файл «glossary.json» со словарем игровых терминов и сленга для моментального перевода (0 мс).
5. Горячие клавиши: Нажмите «Ctrl + D» в любом месте, чтобы вызвать полупрозрачное окно ввода. Введите текст на китайском и нажмите «Enter» — перевод автоматически скопируется, и фокус вернется в игру. Нажмите «Ctrl + V» и «Enter» в игре для отправки. Это на 100% безопасно и не обнаруживается античитами.

📂 Описание файлов в папке:
- 上古世纪快捷中译俄输入工具.exe — Главный файл программы.
- config.json — Файл конфигурации (можно настроить API DeepSeek/OpenAI через меню в трее).
- glossary.json — Локальный словарь терминов и сленга (можно редактировать прямо в настройках).
- translation_cache.db — Локальная база данных кэша переводов (создается автоматически, ускоряет повторные переводы).
